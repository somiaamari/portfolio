## Tech stack

- React 19
- Vite
- CSS
- React Icons
- Netlify

## Run locally

Requires Node.js and npm.

```sh
npm install
npm run dev
```

Vite prints the local development URL in the terminal.

## Build

```sh
npm run build
npm run preview
```

The production site is generated in `dist/`.

## Deploy on Netlify

The site is configured to build with `npm run build` and publish `dist/` via
[`netlify.toml`](./netlify.toml). Connect this GitHub repository to Netlify to
deploy the production branch, or create a deploy preview from a pull request.
No site environment variables or contact-form credentials are required.
